# AGENTS: Desktop tests

Обязательны общие [правила](../AGENTS.md) и все [desktop-инварианты](../src/AGENTS.md). Этот каталог содержит desktop-тесты; серверные тесты находятся в `backend/tests/`.

Unit-тесты мокают внешние адаптеры; таймеры — через Vitest fake timers. Багфикс начинается с падающего регрессионного теста. Проверки и ограничения reviewer — по §11 корневого AGENTS.md.
