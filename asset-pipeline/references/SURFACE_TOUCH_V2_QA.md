## Воспроизводимость

[Рецепт](normalization-2026-09.json), запись `body_surface_touch`, хранит путь
нового пака и SHA-256. Экспорт читает этот файл из рабочей папки, проверяет hash,
нарезает силуэты и масштабирует. Старое поле `bakedFace` удалено. Hash прежних
четырёх рабочих PNG разрешает заменить именно проверенную предыдущую версию;
неизвестные изменения отвергаются. Исходный пак не перезаписывается экспортом.

```bash
.venv/bin/python asset-pipeline/scripts/normalize_reviewed.py
.venv/bin/python asset-pipeline/scripts/normalize_reviewed.py --apply
.venv/bin/python asset-pipeline/scripts/normalize_reviewed.py --check
```

Обычный `process_sprites.py --force` пропускает проверенный набор. Таким образом,
повторная обработка не восстанавливает кривое наложение старых глаз.
