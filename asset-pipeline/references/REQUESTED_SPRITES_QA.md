# Приёмка запросов AUTO-I04/I05/I06 и #48 — 2026-09-07

Арт-доработка завершена: семь наборов по четыре кадра, 28 PNG RGBA 512×512 в
[рабочих папках](../../public/assets/sprites/body/). Референс — [etalon.png](../etalon.png).
Все семь наборов зарегистрированы в runtime-манифесте 2026-09-07 по поручению пользователя. Экспорт PNG сам по себе манифест не изменяет; регистрация выполнена отдельно с сохранением покадровых метаданных.

## Выполненные исправления

- Новые посадка, успокаивание и сон сидя: компактные пропорции, прозрачный фон, без нарисованной опоры.
- Нарезка по раздельным силуэтам сохраняет исходное сглаживание контура и исключает отдельный мусор вокруг фигур.
- Масштаб задаётся расстоянием от макушки до подбородка (140 px), а не общей высотой силуэта: поднятые руки не уменьшают голову и тело.
- Ручная покадровая разметка рук, головы, лица, таза и pivot сохранена в [рецепте](requested-sprites-export.json). Координаты преобразуются вместе с изображением; это визуальная разметка, а не автоматическое распознавание суставов.
- Общие кадры: grab 03 = pull-up 00; sit 01 = settle 00; settle 03 = sleep 00. Совпадение PNG проверяется по SHA-256.
- Сидение и сон используют цикл 0–1–2–1; игровой жест возвращается точно в исходный кадр. Повторы кадров намеренные.

## Проверки и воспроизведение

Команды находятся в [README](../README.md). Проверено: 28 файлов, формат RGBA, холст 512×512,
реальная прозрачность, отсутствие пикселей на границах холста, попадание anchors/pivot в холст,
стыки общих кадров и дрейф pivot сидения/сна не более 1 px после округления.
Контактные листы просмотрены на светлом и тёмном фоне: персонажи целиком видны,
нет прямоугольного фона; позы и порядок кадров соответствуют запросам.

Локальные проверки инструментов: 26 тестов, результат OK (`skipped=6`) из-за недоступности
символических ссылок в Windows. Исправлен ошибочный повторный unlink в таком пропуске.
Регрессионный тест подтверждает защиту ручного размещения от обычной нарезки с `--force`.
На этапе доработки PNG продуктовые тесты и build не запускались.

После регистрации: строгая проверка манифеста — 46 анимаций, 188 файлов, ноль ошибок и
предупреждений; существующие записи сохранены. Тесты manifest-loader/asset-resolver —
62 прошли, `npm run typecheck` — успешно. Тест отсутствующего sit_edge теперь использует
явно подготовленный манифест без этого ключа; выбор зарегистрированного набора проверяется отдельно.

## Передача в приложение

Все семь наборов зарегистрированы с `faceOverlay.mode: baked_in`, `fallback: none`.
Полное лицо поверх PNG не накладывать. Покадровые bounds измерены по alpha; anchors/pivot
получены из ручной разметки; длительности — предложенный художественный темп.
Зацеп и подъём привязываются к рукам, посадка — к тазу, полёт — к root.
Сценическое перемещение и контакт с реальной опорой проверяются при подключении в приложении;
GIF показывает только кадры на холсте. Новые ключи зарегистрированы художником в [манифесте](../../public/assets/sprites/manifest.json).
Изменения FSM и маршрутизации действий остаются отдельной работой разработчика.
