формат референсов; фактическая нарезка по четырём силуэтам через существующий
`extract_reviewed`, а не по предполагаемым квадратным ячейкам.

параметры экспорта, не новый контракт движка. Обычные позы: центр X=256,

Y=500 с (256,330), где находятся root/hips/pivot; head и bounds пересчитаны
вместе с PNG. Кадр 03 повторяет 01 для цикла 0–1–2–1. SHA-256 паков и
предыдущих разрешённых PNG зафиксированы в [рецепте](normalization-2026-09.json).

Обновлены только пять назначенных записей манифеста. Остальные 43 записи,
все URL, порядок и длительности сохранены. Все пять теперь `baked_in`,
`fallback: none`, без старых face anchors. Лицо не наклеивается при экспорте.

## Защита от второго лица

Обычный `AssetResolver.resolveFace` уже разрешал только `overlay`.
Найден и воспроизведён тестом обход в `resolveDebugSelection`: выбранное лицо
добавлялось поверх любого тела. Исправлен guard по режиму совместимости;
проверены normal/debug для пяти наборов, get_up, look_around и surface_touch.
Полнохолстовый отладочный просмотр лица остаётся доступен на overlay-телах.
Удаление покадровых face anchors также отключает слежение за курсором для
тела с уже нарисованным лицом. Правила FSM не менялись.

Старый экспорт `requested-sprites-export.json` содержит прежний sit_edge;
он помечен supersededBy и отклоняется до записи, чтобы не вернуть артефакты.
Текущий повторяемый экспорт: `normalize_reviewed.py --apply`.
