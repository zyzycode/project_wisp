## Исторические запросы ассетов AUTO-I02

Из прежнего Interaction pack сохранены запросы специальных sheets: cursor head tilt → fallback `body_thinking` + `face_curious`; cursor pointing → `body_thinking` + `face_winking`/sparkle; cursor reach → `body_wave` + `face_curious`. Приветствие использовало `body_wave` + happy/heart. Это историческое свидетельство, не текущий перечень недостающих ассетов: перед новым запросом проверить manifest. Графику предоставляет внешний художник-человек.
