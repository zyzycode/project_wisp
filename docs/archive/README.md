# Общий архив задач и проверок

Эти материалы затрагивают обе стороны desktop ↔ backend и описывают конкретные commits и поставки. Статусы, команды, пути и разовые разрешения не являются текущими инструкциями; актуальная документация — [навигатор](../README.md).

Связанный с текущей Issue architect result и его Implementation consequences остаются обязательными по [AGENTS.md](../../AGENTS.md). Архивирование сохраняет требования и доказательства; оно не подтверждает исполнение gate и не отменяет контракт. При конфликте применяется процедура из AGENTS, а не выбор удобной версии. Для новых задач текущие структура и commands определяются навигатором, включая общее расположение fixtures.
