# 🎨 Техническое задание для художника: Спрайт-пак Project Wisp (MVP)

Данный документ содержит технические требования, структуру папок, правила именования файлов и пошаговый чек-лист задач для создания графических ассетов персонажа.

---

## 1. 📐 Технические стандарты (Критически важно!)

* **Размер холста (Canvas Size):** строго **`512 × 512 px`** для каждого файла.
* **Формат файлов:** `PNG-32` (прозрачный фон RGBA, без подложки).
* **Цветовое пространство:** `sRGB`, 8 bit/channel.
* **Высота персонажа:** примерно **`380 – 420 px`** (в нейтральной позе стоя).
* **Опорная точка (Pivot / Baseline):**
  * По горизонтали: строго по центру (**`X = 256 px`**).
  * По вертикали (линия стоп/опоры): **`Y = 460 px`** от верхнего края (снизу остаётся запас ~50 px под тень/подушку).
* **Правило наложения (Alignment):**
  * Все элементы лица (глаза, рот) рисуются на том же холсте `512×512` на прозрачном фоне ровно в том месте, где находится голова на теле (`body_idle_00.png`), чтобы при наложении без смещения лицо встало идеально.
