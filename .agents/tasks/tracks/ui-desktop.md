## 2. Подробные карточки задач

### [TASK: P14-UI01] — Context Menu & Interaction Polish
- **Исполнитель:** `app-developer`
- **Цель:** Расширить контекстное меню (по правому клику на персонажа) новыми опциями:
  - **Интерактив:** Погладить, Поиграть, Покормить (отправляют стимулы в Character Engine).
  - **Принудительные позы:** Сесть, Лечь, Встать, Бегать (для быстрого тестирования).
  - **Управление окном:** Сбросить позицию по центру экрана, Закрепить поверх всех окон.
  - **Инструменты:** Переключатель отображения Debug HUD.
- **Читать:**
  - `.agents/agents/app-developer/agent.md`
  - `src/renderer/ui/`
- **Менять:** `src/renderer/` (модули контекстного меню), unit-тесты.
- **Критерии приёмки:**
  - [ ] Меню открывается по правому клику в позиции курсора и не выходит за границы экрана.
  - [ ] Клики по пунктам меню генерируют корректные действия в Character Engine / Window Manager.
  - [ ] Меню закрывается при клике вне его области.
  - [ ] `npm test && npm run typecheck` проходят без ошибок.
- **Вне скоупа:** не менять логику FSM и Main-процесс.
