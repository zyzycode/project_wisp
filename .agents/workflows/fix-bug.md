# fix-bug.md — Регламент исправления ошибок (Bugfix)

Регламент для локализации и устранения дефектов в Project Wisp.

---

## 1. Воспроизведение и локализация
1. Проанализируй стек вызовов ошибки или описание некорректного поведения.
2. Локализуй точное место возникновения сбоя (процесс: Main, Preload или Renderer; модуль; функция).
3. Определи фундаментальную первопричину (Root Cause), а не маскируй симптомы.

---

## 2. Разработка минимального фикса
- **Строгий запрет:** Категорически запрещено переписывать модуль целиком или менять соседний код, не имеющий отношения к ошибке.
- Внеси точечное изменение, устраняющее сбой.
- Проверь, чтобы фикс не ломал существующие контракты и обратную совместимость.

---

## 3. Регрессионное тестирование
1. Напиши юнит-тест (Regression Test), который воспроизводит условие сбоя до фикса и успешно проходит после применения фикса.
2. Запусти полный набор тестов: `npm test`.
3. Запусти `npm run typecheck` и `npm run lint`.

---

## 4. Итоговый отчёт
Укажи в ответе:
- Первопричину дефекта.
- Описание точечного исправления.
- Ссылки на изменённые файлы и добавленный тест.
