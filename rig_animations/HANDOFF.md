# Передача в отдельный проект

Перенос подготовлен 2026-10-19. Открыть [README](README.md), затем [WORKFLOW](docs/WORKFLOW.md). История неудачных попыток удалена из рабочего каталога; краткие причины сохранены в WORKFLOW. История Git монорепозитория не переписывалась.

1. Распаковать `transfer/wisp-rig-approved-2026-10-19.tar.gz` в выбранный новый каталог. Архив содержит одну папку `wisp-rig/`, включая исходник, PNG, проекты, приёмки, инструкции, каталог поз и инструменты.
2. Выполнить `python3 scripts/verify_package.py` из `wisp-rig`. Все пути относительные; asset-pipeline и монорепозиторий не требуются.
3. Установить редактор через `python3 scripts/bootstrap.py`, запустить `python3 scripts/editor.py`. Старые токены, editor state и кеши не переносить.
4. Открыть `work/gaze-01/r08/gaze-01-r08.psd2live` в PSD2Live. Сохранять дальнейшие изменения в новой рабочей копии.
5. Следующая итерация руки: маски исходной руки + исходного рукава → точная нейтральная сборка всего персонажа → просмотр пользователем. Не продолжать r16.

Новый репозиторий и Codex-задача ещё не создавались: пользователь пока не указал место. Архив переносит текущий проверенный срез, а не рабочие приватные настройки. Новые незакоммиченные заметки ControlNet в исходном checkout сохранены, но в срез не включены. Информация asset-pipeline перенесена как справочный снимок; исходные таблицы и продуктовый runtime не менялись.
