## Инструменты

PSD2Live 3.5.1 зафиксирован в [tools.lock.json](tools.lock.json). Все команды выполнять из корня этого каталога:

```sh
python3 scripts/verify_package.py
python3 scripts/bootstrap.py
python3 scripts/editor.py
python3 scripts/mcp.py call workspace_inspect '{"scope":"project"}'
```

Для просмотра откройте `reviews/index.html` локально. Проверка файлов не требует редактора или сторонних Python-пакетов. Установка редактора требует сети; MCP работает на loopback. `smoke_test.py` — отдельная интеграционная проверка инструмента, не рига; требует Pillow. Она не входит в очистку или перенос.

Не переносить `.local` (токен и настройки), `.cache`, `.tools`, `.git` родительского проекта. В новом месте создать собственные настройки редактора через bootstrap/editor. Рабочие PNG и native-проекты сейчас исключены из Git: для переноса использовать полный архив, а не один `git clone`.
