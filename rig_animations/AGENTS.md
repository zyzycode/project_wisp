# Wisp rig authoring

Это самостоятельный проект подготовки персонажа; продуктового кода здесь нет. Читать README.md, docs/WORKFLOW.md и skills/wisp-psd2live/SKILL.md. Они определяют текущее состояние и этапы.

- Работать как rigger: маски исходных пикселей, слои, технические сетки, деформеры, параметры и motion в PSD2Live.
- Исходник и принятые файлы не перезаписывать. Новая работа — отдельная копия в work/. При прямом поручении пользователя удалить неудачные варианты, сначала проверить зависимости принятых файлов и записать список удаления.
- Один участок и один этап за итерацию; техническую работу текущего этапа выполнять автономно. Приёмка фрагмента не принимает весь риг. Пользовательская приёмка имеет приоритет над автоматическими оценками.
- Для руки сначала маски оригинала и нейтральная обратная сборка; весь персонаж показывать на каждом этапе. Генерация скрытых областей — только в разрешённом пользователем объёме, одна картинка за запрос.
- Не переносить сюда продуктовые ограничения и runtime код. Каталог motions — справочник намерений и существующих спрайтов, не доказательство готовности рига.
- Верификация: сохранность исходника/принятых файлов, визуальная проверка, save/reopen при изменении проекта; при экспорте — проверка результата в проигрывателе. Продуктовые тесты не нужны.
- Не публиковать токены, приватные editor preferences, кеши. Binaries и work/ не попадают в Git автоматически; архивировать принятые assets отдельно и проверять SHA-256.
