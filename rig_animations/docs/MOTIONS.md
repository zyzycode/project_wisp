## Последовательности и контакты

- `body_drink_tea`: кружка с паром у груди → поднести и подуть → глоток → опустить со вздохом.
- `body_listen_music`: наклон головы влево → полуприсед в центре → наклон вправо → центр; светящиеся наушники.
- `body_peek_wall`: осторожный взгляд → лицо и руки за краем → максимальный наклон → спрятаться. Требуется отдельно определить перекрытие вертикальным краем.
- `body_read_book`: чтение → поднять страницу → перелистнуть → пригладить.
- `body_typing`: левая рука → правая → обе → радостный кивок; сидит с ноутбуком.
- `body_wave`: рука к плечу → взмах у щеки вправо → влево → центр. Сохранить масштаб головы и торса.
- `body_land`: контакт → амортизация → подъём → совпадение с idle; не добавлять второе проседание.
- `body_pull_up_edge`: вис → подтягивание → перенос ноги → присед; руки требуют покадрового контроля контакта.
- `body_cursor_caught`: хватание → радость → нейтраль; `body_cursor_missed`: взгляд вслед цели → опускание рук → нейтраль.

Стыки проверены по SHA-256 текущих PNG, индексы кадров начинаются с 0:

| Стык / цикл | Результат 2026-10-19 |
|---|---|
| grab_edge 03 → pull_up_edge 00 | Идентичны |
| sit_edge 01 → sit_edge_settle 00 | **Не идентичны**; старый QA устарел после замены sit_edge |
| sit_edge_settle 03 → sit_edge_sleep 00 | Идентичны |
| cursor_play 00 и 03 | Идентичны; точный возврат |
| sit_edge 01 и 03; sit_edge_sleep 01 и 03 | Идентичны; документирован цикл 0–1–2–1 |

Для сидения на краю контакт/pivot/hips `(256,330)`; реакции на курсор используют root/pivot `(256,460)`. У зацепа края root/pivot расположен у контакта рук, приблизительно `(256,70)`; точные значения меняются по кадрам и сохранены в JSON. Координаты относятся к холсту спрайта 512×512, их нельзя напрямую переносить в исходник рига 1024×1536.

## Лица, зрачки и эффекты

- Зарегистрированы 14 наборов лица: `face_happy`, `face_sad`, `face_shocked`, `face_sleep`, `face_talking`, `face_thinking`, `face_angry`, `face_pout`, `face_winking`, `face_curious`, `face_dizzy`, `face_flirty`, `face_gaze`, `face_gaze_base`.
- Зарегистрированы `pupils_normal` и `pupils_gaze`. Все наборы лица/зрачков содержат по 4 кадра. `face_gaze_base` и `pupils_gaze` — статические повторяющиеся кадры, не четыре направления; старый QA проверял смещения ±2 px X / ±1 px Y.
- Плановые лица: `face_blink`, `face_crying`, `face_embarrassed`, `face_panic_scream`, `face_smug`, `face_sparkle_eyes`.
- Девять плановых предметов/эффектов: `prop_exclamation`, `prop_heart`, `prop_lightbulb`, `prop_music_notes`, `prop_pillow`, `prop_question`, `prop_sparkle`, `prop_sweat_drop`, `prop_zzz`. Их последовательности сохранены в JSON.

`overlay` разрешает совместимый слой мимики, `baked_in` уже содержит лицо. Для большинства тел выбран `baked_in`; `body_idle` и `body_edge_peek` имеют `overlay` с явным списком разрешённых лиц. Pivot лица совмещается с anchor тела; покадровый anchor заменяет default, не прибавляется к нему. Это сведения о прежнем формате экспорта, не предписание генерировать новые листы: в риге каждый новый слой генерируется отдельной картинкой по согласованному процессу.

## Замечания, которые нельзя потерять

- `body_bored`: исторический дефект слишком узкого силуэта; `body_scared`: уменьшенная масса тела; `body_wave`: тело меньше на 15–20%. Наличие файлов не снимает эти замечания.
- `body_idle`: журнал упоминал 8 кадров, фактический манифест содержит 4. Не восстанавливать 8 без отдельного решения.
- `body_land`: конфликтующие старые оценки; требуется визуальная проверка приземления и стыка с idle.
- «Готово*» означает перенесённую оценку без свежего визуального аудита. «Готово (геометрия)» подтверждает ограниченную проверку геометрии, а не полную анимационную приёмку.
- Замена sit_edge нарушила прежнее обещание общего кадра с settle; сохранить посадочный контакт недостаточно для плавного перехода.
- Холст 512×512, четыре кадра минимум и старые шаблоны sprite-sheet описывают прежний pipeline. Они не ограничивают рабочий холст или число ключей нового непрерывного рига.
